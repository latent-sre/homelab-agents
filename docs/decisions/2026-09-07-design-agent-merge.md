Accepted by the operator on 2026-09-07; implementation starts from main `8486439`.

## Decision

Keep `principal-engineer` and absorb `distinguished-architect` into it. Both agents already had
the same explicit tools, document-only writing mandate, guarded inspection shell, and
caller-mediated implementation handoff. Their distinction was reasoning depth and time horizon.
Keeping the principal name preserves existing system-design callers without adding a new label.

System design stays scoped to existing strategy. Platform standards, build/buy choices, and
multi-year commitments trigger deeper framing, failure-domain, staffing, data-gravity, cost,
falsifier, and evolution analysis within the same engagement. The eng-ladder skill retains its
builder, principal, and distinguished assessment depths; both design depths name principal.
Builder-owned work with one consequential fork still receives a scoped required consult.

Retain the existing principal tool grant and guard membership. Remove the retired identity from
the hook's fast path and failure fallback, the guard's two rosters, and generated host profiles.
Codex's inherited delegation authority remains a cooperative no-spawn rule; Copilot omits its
agent and execute tools. Document-only editing remains cooperative on all hosts.

## Compatibility and rollback

This is a one-shot component retirement, with no alias or second routing identity. Calls naming
the retired agent must change to principal. Regeneration removes its managed adapters; existing
host installations need the documented normal update/sync before this roster is active there.
No host installation is changed by this local refactor. Historical decisions remain historical.

Rollback restores the canonical pair, references, hook rosters, evaluator assertions, and
generated files together. There is no persisted record-shape migration to reverse. Keeping an
alias was rejected because it retains the duplicated selection surface the merger removes.
